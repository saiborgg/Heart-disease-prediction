# Heart-disease-prediction
This project aims to predict the likelihood of heart disease in patients using machine learning models trained on clinical data. It provides a complete pipeline from data cleaning to model evaluation.

Technologies Used
Python

Jupyter Notebook

Pandas, NumPy for data handling

Scikit-learn for machine learning

What It Does
Loads and preprocesses heart disease dataset

Performs exploratory data analysis

Applies feature scaling and selection

Trains models like Logistic Regression, SVM, Random Forest, KNN

Evaluates model performance using standard metrics

How to Use
Clone this repository

Install dependencies:

bash
Copy
Edit
pip install -r requirements.txt  
Run the notebook inside the notebooks/ folder

Dataset
Uses the Cleveland Heart Disease dataset from the UCI Machine Learning Repository.
